# Состояние работы на 02.11.2026: верификация образов на плате

Срез составлен 02.11.2026 по результатам измерений на плате ALINX VD100 (AMD Versal XCVE2302).
Все замеры выполнены непосредственно на аппаратной платформе через штатную UART-консоль и SD-карту.

---

## 1. Новые результаты замеров на плате (02.11.2026)

### 1.1. Большой IP-блок: OTBN + KMAC (OpenTitan), алгоритм ML-DSA-87 по контракту (`uvm_c`)
* **Образ ПЛИС:** `BOOT_otbn.BIN` (45 МГц, WNS +0,421 нс).
* **Тестбенч:** UVM-тест по контракту (`examples/otbn/uvm_c`, `tb_top` AArch64 на Cortex-A72).
* **Эталон:** `mldsa-native` через DPI, сверка каждого ответа шины (`rsp`).

| Конфигурация | Команд / тактов DUT | ПК (оценка по 140 с/раунд) | Плата VD100 [изм.] | Выигрыш | Результат |
|---|---|---|---|---|---|
| **5 раундов** | 12,7 млн тактов | 11,7 мин | 16,74 с | ×42 | **PASS**, 37 432 ответа сверено, 0 ошибок |
| **20 раундов** | 67,3 млн тактов | 46,7 мин | 53,46 с | ×52 | **PASS**, 126 727 ответов сверено, 0 ошибок |
| **50 раундов** | 182,5 млн тактов | **1,94 ч** (7 000 с) | **2 мин 07 с** (127,2 с) | **×55,0** | **PASS**, 305 317 ответов сверено, 0 ошибок |
| **75 раундов** | 274,4 млн тактов | **2,92 ч** (10 500 с) | **3 мин 37 с** (217,1 с) | **×48,3** | **PASS**, 454 142 ответа сверено, 0 ошибок |

> **Значение для диплома и статьи:**
> Прогон 75 раундов закрывает требование многочасового эквивалента на ПК для большого IP по контракту (FOCUS §4.9). Тест, который на ПК идёт **почти 3 часа**, на плате завершается за **3,6 минуты** с полной потранзакционной верификацией ответов криптоускорителя.

### 1.2. 64-битное процессорное ядро: cv64a6 (CVA6 RV64IMAC) по контракту (`uvm_c`)
* **Образ исправного ядра:** `BOOT_cva6_64.BIN` (50 МГц).
* **Образ с ошибкой:** `BOOT_cva6_64_fault.BIN` (50 МГц, внесённая ошибка переноса `instret[31:0] -> [63:32]`).
* **Эталон:** Spike RV64.

| Тест / программа | `BOOT_cva6_64.BIN` (исправное) | `BOOT_cva6_64_fault.BIN` (с ошибкой) | Описание проверки |
|---|---|---|---|
| **`rv64_basic`** | **PASS** (2,24 с, 8 023 инстр.) | **PASS** (2,21 с, 8 023 инстр.) | Базовый набор инструкций RV64 |
| **`minstret64`** | **PASS** (0,75 с, 200 052 инстр.) | **MISMATCH** (0,48 с, окно `regw` 0..4095) | Проверка переноса в 32-й бит счетчика инструкций |
| **`nettle-aes_s1`** | **PASS** (9,51 с, 4,65 млн инстр.) | **PASS** (9,47 с, 4,65 млн инстр.) | Короткий криптографический тест |
| **`nettle-aes_s1100`** | — (ожидается ~1,8 ч) | **MISMATCH** (105 мин 50 с vs ~75 ч ПК, **×42**) | Ошибка поймана после перехода за $2^{32}$ команд |

### 1.3. 32-битное процессорное ядро: CVA6 cv32a60x (проверка исправного ядра и ошибки `minstreth`)
* **Образ исправного ядра:** `BOOT_cva6.BIN` (50 МГц).
* **Образ с ошибкой:** `BOOT_cva6f.BIN` (50 МГц, потерян перенос `instret[31:0] -> [63:32]`).
* **Эталон:** JIT-модель RV32IMC на Cortex-A72.

| Тест / программа | `BOOT_cva6.BIN` (исправное) | `BOOT_cva6f.BIN` (с ошибкой) | Описание проверки |
|---|---|---|---|
| **`minstret.hex`** | **PASS** (0,192 с, 200 045 инстр.) | **MISMATCH** (0,23 с, запись 20: `rd=0x13 dut=0x0 model=0x1`) | Аппаратный перенос в `minstreth` |
| **`nettle-aes_s1`** | **PASS** (0,314 с, 4 074 031 инстр.) | **PASS** (0,314 с, 4 074 031 инстр.) | Отсутствие ложных срабатываний до $2^{32}$ |
| **`coremark.hex`** | **PASS** (0,269 с, 2 785 495 инстр.) | — | Полный прогон CoreMark на частоте ПЛИС |
